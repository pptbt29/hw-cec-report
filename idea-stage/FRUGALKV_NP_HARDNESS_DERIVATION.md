# FrugalKV 有限时域离线问题的 NP-hard 证明

## 1. 需要证明的命题

**命题。** FrugalKV 的有限时域离线优化问题是 NP-hard。即使系统只有一个目标节点、一类共享资源、每个 session 只有一个“完整准备或不准备”的动作、所有可能返回都位于同一个已知时间窗口、返回概率已知、没有淘汰和路由不确定性，这一结论仍然成立。

这里的“离线”表示系统事先知道研究时域内各 session 的候选动作、资源成本和返回概率；“有限时域”表示只考虑一个有限的决策窗口。本文不把一般的在线随机控制问题称为 NP-complete。

## 2. 受限的 FrugalKV 决策问题

给定 $n$ 个 session。对 session $i$：

- 完成准备需要消耗 $w_i$ 单位后台资源；
- 完成准备可增加 $v_i$ 单位预期 SLO-goodput；
- 不准备的资源消耗和收益均为 $0$。

系统总资源预算为 $\mathcal B$，目标收益门限为 $P$。决策问题是：是否存在一个 session 集合 $S$，使得

$$
\sum_{i\in S} w_i \le \mathcal B
$$

并且

$$
\sum_{i\in S} v_i \ge P?
$$

$v_i$ 表示准备 session $i$ 后增加的预期 SLO-success 数。对任意 0–1 knapsack 整数价值 $q_i$，令 $Q=\sum_i q_i$，并让 session $i$ 在窗口内以概率 $q_i/Q$ 返回；准备后，该请求在返回时满足 SLO，不准备时则不满足。于是其预期收益为 $v_i=q_i/Q$。该归一化不改变可行子集，因此不需要在主目标中额外引入人为请求权重。

## 3. 从 0–1 knapsack 归约

任取一个 0–1 knapsack 决策实例：物品 $i$ 的重量为 $w_i$、价值为 $q_i$，背包容量为 $\mathcal B$，目标价值为 $Q_0$。

为每个物品创建一个 session：

1. 把物品重量 $w_i$ 映射为该 session 完成 KV 准备所需的后台资源；
2. 把物品价值 $q_i$ 归一化为返回概率 $v_i=q_i/Q$，并设置目标收益 $P=Q_0/Q$；
3. 选择物品等价于准备该 session，不选择物品等价于等待。

该映射只需线性时间。于是，存在重量不超过 $\mathcal B$ 且价值至少为 $Q_0$ 的物品集合，当且仅当存在资源消耗不超过 $\mathcal B$ 且预期 SLO-goodput 至少为 $P$ 的 session 准备集合。

0–1 knapsack 决策问题是 NP-complete，因此上述受限 FrugalKV 决策问题是 NP-hard。完整 FrugalKV 还允许多个节点、多类资源、迁移与重算组合、部分 KV block、淘汰和时间耦合；它包含该受限问题作为特例，所以完整的有限时域离线优化问题也是 NP-hard。

## 4. 统一资源—SLO 目标为什么没有降低复杂度

主问题使用统一目标：

$$
J(x)=G(x)-C(x),
$$

其中 $x$ 是各 session 是否执行准备的 0–1 决策向量，$G(x)$ 是全局 SLO-goodput，$C(x)$ 是加权资源代价。令受限特例中的资源代价权重为 0，则 $C(x)=0$，最大化 $J(x)$ 就退化为最大化 $G(x)$，仍然包含上一节的 0–1 knapsack。因此，把 SLO 收益与资源代价写入同一目标函数不会降低最坏情况的计算复杂度。论文应把在线算法表述为近似方法，并在小规模实例上与离线最优解比较。

## 5. 结论边界

- 可以写：**有限时域离线 FrugalKV 是 NP-hard。**
- 不应写：一般在线随机 FrugalKV 是 NP-complete。
- Introduction 只需放一句结论；完整受限条件和归约应放在 Problem Formulation 或附录。
- NP-hard 只说明精确联合求解在一般情况下困难，不自动证明本文在线算法有效；算法质量仍需通过最优差距、资源效率和运行开销实验验证。
